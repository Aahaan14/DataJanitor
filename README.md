# DataJanitor — frontend

React 19 · TypeScript · Vite · Tailwind CSS 4 · React Router.

```bash
npm install
npm run dev        # http://localhost:5173  (proxies /api to http://127.0.0.1:8000)
npm run build      # type-check + production build in dist/
npm run typecheck
npm test           # real-backend tests; set DJ_PYTHON to the backend's Python
```

See the main [README](../README.md#frontend-phase-8) for pages, configuration and test details.
