# Demonstration data

`data_quality_demo.csv` is synthetic and contains intentionally varied data-quality cases for a safe local demonstration. It includes blank and placeholder cells, whitespace/case variants, a repeated customer row, a malformed date, non-numeric values, negative values, and a high amount that may be an outlier. These examples are intentionally not all labelled as confirmed errors: the user should review every proposal and preserve uncertain values. Do not use this sample to make real business decisions.
